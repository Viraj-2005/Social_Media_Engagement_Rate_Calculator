Supported URL Formats

  • youtube.com/@handle (channel handle)
  • youtube.com/c/customname
  • youtube.com/channel/CHANNEL_ID
  • youtube.com/user/username (legacy)

Handles and custom URLs are resolved to channel IDs automatically.

API Quota

  • ~1 unit — channel info
  • ~1 unit — playlist items (50 videos)
  • ~1 unit — video statistics (50 videos)
  • ~3–5 units per 20-video channel analysis

Daily limit: 10,000 units. Higher video counts use more quota.
